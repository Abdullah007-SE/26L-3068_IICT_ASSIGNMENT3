# 26L-3068_IICT_ASSIGNMENT3
My Mini Store

A small storefront featuring five products from books, food, and gadgets.
It includes product details, categories, and a form to subscribe to updates.

CSS Precedence

- The tagline is green (`#006400`) because its inline style overrides the internal and external paragraph colors.
- The other paragraphs are dark red (`#8b0000`) because the internal style overrides the external paragraph color.
- Specificity determines which rule applies; for this assignment, the order is inline > internal > external.
